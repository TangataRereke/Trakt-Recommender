WHAT DOES IT DO?
----------------
Add recommendations to your own lists from shows on trakt. It'll filter out shows that aren't finished and filter out non-English shows. Skip will mean it will never show up again.

You can add your own configuration things in as you feel you need to. This is all hard coded for now.

This is currently for Ubuntu 24.04+ / C++

SETUP
-----
Setup your details in config.json.example and save as config.json.

You'll need the playlists setup with the same stubs or change them.

Call make.sh to build.
